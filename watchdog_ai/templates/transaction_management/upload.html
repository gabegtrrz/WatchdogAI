Required CSV Columns:

  • item_name - Name or description of the item being procured
  • quantity - Number of units of the item being procured
  • unit_purchase_price - Price per unit of the item being procured
  • transaction_date - Date when the transaction was completed (YYYY-MM-DD)
  • procurement_method_name - Method used for procurement (e.g., Public Bidding, Direct Contracting)
  • supplier - Supplier or vendor for this transaction
  • invoice_number - Invoice number for this transaction
  • payment_receipt_number - Payment receipt number for this transaction
  • project_name - Name of the project for this procurement transaction
  • end_user_unit - End user unit or department for this procurement
  • project_description - Detailed description of the project
  • approved_budget - Approved Budget for the Contract (ABC)
  • procurement_officer - Name of the procurement officer responsible
  • invitation_to_bid_posting_date - Date the Invitation to Bid was posted (YYYY-MM-DD)
  • bid_submission_deadline - Deadline for bidders to submit proposals (YYYY-MM-DD)
  • bid_opening_date - Date when bids were publicly opened (YYYY-MM-DD)
  • notice_of_award_date - Date the Notice of Award was issued (YYYY-MM-DD)
  • contract_signing_date - Date the formal agreement was signed (YYYY-MM-DD)

Optional CSV Columns:

  • transaction_id - Unique identifier (auto-generated if not provided)
Note: All date fields should be in YYYY-MM-DD format. All fields are required except transaction_id and average_price.
